Fiche 1Le vocabulaire des commandes turtle

Les commandes Python sont des mots anglais : si tu connais le sens du mot, tu devines ce que fait la commande. Le nombre entre parenthèses s'appelle l'argument : il précise de combien la tortue avance ou tourne.

Clique sur une case floue pour vérifier ta réponse.
FamilleCommandesLe mot anglais à retenir
Se déplacerforward() backward() goto()forward = vers l'avant ; backward = vers l'arrière ; go to = aller à
Tournerleft() right() setheading()left = gauche ; right = droite ; heading = direction, cap
Le crayonpenup() pendown() pensize()pen = stylo ; up = levé ; down = baissé ; size = taille
La couleurcolor() begin_fill() end_fill()fill = remplir ; begin = commencer ; end = finir
Les formescircle()circle = cercle
Le réglagespeed() done()speed = vitesse ; done = terminé

Les pièges classiques

  • left et right font tourner la tortue sur place : elle ne dessine rien.
  • Quand le crayon est levé, la tortue se déplace sans tracer. Pense à le reposer.
  • begin_fill() et end_fill() vont toujours par paire : l'un avant la figure, l'autre après.
  • Les angles sont en degrés : un quart de tour vaut 90, un demi-tour 180, un tour complet 360.
Je m'entraîne

Fiche 2La structure d'un programme

Un programme commence par importer la bibliothèque, puis donne les instructions une par ligne, que Python exécute de haut en bas.

from turtle import *     # 1. j'importe la bibliothèque

forward(100)             # 2. les instructions,
left(90)                 #    une par ligne,
forward(50)              #    dans l'ordre

Le vocabulaire à maîtriser

  • Bibliothèque (ou module) : une boîte d'outils déjà écrits. turtle pour la tortue, robot pour le robot du test.
  • Importer : rendre ces outils disponibles. Sans la ligne d'import, Python ne connaît pas forward ni avancer.
  • Instruction : un ordre donné à l'ordinateur.
  • Séquence : une suite d'instructions exécutées dans l'ordre. Changer l'ordre change le dessin.
  • Commentaire : tout ce qui suit #. Python l'ignore ; il sert au lecteur humain.

Les règles d'écriture

  • Une instruction par ligne.
  • Toujours des parenthèses après le nom d'une commande, même vides : penup(), droite().
  • Pas d'accent, pas d'espace dans un nom, et les minuscules comptent : Forward n'est pas forward.
  • L'import s'écrit une seule fois, tout en haut.
Je m'entraîne

Recopie un programme vu en classe, intervertis deux lignes, et dessine les deux versions côte à côte pour voir ce qui change.

Fiche 3La boucle for et range

Une boucle répète un bloc d'instructions un nombre de fois connu à l'avance : au lieu d'écrire dix fois la même chose, on l'écrit une fois et on dit combien de fois la répéter.

for i in range(nombre_de_tours):
    instruction_1      # le corps de la boucle :
    instruction_2      # répété à chaque tour
instruction_3          # après la boucle : exécutée une seule fois

Les quatre éléments de la première ligne

  • for : le mot qui annonce la répétition (« pour »).
  • i : la variable de boucle, qui compte les tours. Son nom est libre (i, k, tour, loop).
  • in range(...) : combien de fois, ou quelles valeurs prend la variable.
  • : les deux-points, obligatoires en fin de ligne.

Ce que donne range

ÉcritureValeurs prises par la variableNombre de tours
range(n)de 0 jusqu'à n, n exclun
range(début, fin)de début jusqu'à fin, fin excluefin moins début
range(début, fin, pas)de début, en ajoutant le pas, sans atteindre finà compter

À retenir pour réussir

  • Avant d'écrire une boucle, repère le motif qui se répète dans la figure, puis compte combien de fois il revient.
  • Pour une figure régulière qui se referme, la tortue fait un tour complet : la somme de tous ses virages vaut 360°.
  • La variable de boucle peut servir dans le corps, par exemple comme longueur qui change à chaque tour.
Je m'entraîne

Invente cinq range différents (avec 1, 2 et 3 nombres) et écris pour chacun la liste des valeurs prises par la variable et le nombre de tours.

Fiche 4L'indentation

En Python, le retrait au début d'une ligne (l'indentation) n'est pas décoratif : c'est lui qui dit quelles lignes sont dans la boucle et lesquelles n'y sont pas.

for i in range(4):
    instruction_A      # 4 espaces : DANS la boucle, répétée 4 fois
    instruction_B      # 4 espaces : DANS la boucle, répétée 4 fois
instruction_C          # 0 espace : HORS de la boucle, exécutée 1 fois

Les règles

  • Après une ligne qui finit par :, la ligne suivante est toujours décalée.
  • Le décalage standard est de 4 espaces (ou une touche Tab). Toutes les lignes d'un même bloc ont exactement le même retrait.
  • Une boucle dans une boucle : on ajoute 4 espaces de plus, donc 8 espaces.
  • Revenir à la marge, c'est sortir de la boucle.

Pourquoi c'est décisif au test : deux programmes avec exactement les mêmes lignes peuvent produire deux dessins différents, seulement parce qu'une ligne est décalée ou non. Dans les exercices « suivre le code », regarde d'abord la marge de chaque ligne.

Je m'entraîne

Recopie un programme avec une boucle, puis dé-indente la dernière ligne de la boucle. Dessine les deux trajets et compare-les.

Fiche 5Les boucles imbriquées

Une boucle peut contenir une autre boucle : la boucle intérieure dessine un motif, la boucle extérieure répète ce motif plusieurs fois.

for i in range(3):            # boucle extérieure
    for j in range(4):        # boucle intérieure (4 espaces)
        instruction_A         # 8 espaces : dans les deux boucles
    instruction_B             # 4 espaces : seulement dans l'extérieure

Compter les exécutions

  • Une ligne dans les deux boucles s'exécute (tours de l'extérieure) multiplié par (tours de l'intérieure).
  • Une ligne seulement dans la boucle extérieure s'exécute autant de fois que l'extérieure.
  • La boucle intérieure recommence entièrement à chaque tour de l'extérieure.
  • Les deux variables doivent avoir des noms différents (i et j).

La méthode pour écrire une boucle imbriquée

  1. Repère le petit motif de base dans la figure.
  2. Écris d'abord la boucle qui dessine ce motif seul, et vérifie-la en dessinant son trajet.
  3. Repère comment la tortue doit se placer entre deux motifs.
  4. Enveloppe le tout dans une seconde boucle, en décalant le bloc de 4 espaces.
Je m'entraîne

Pour une boucle imbriquée vue en classe, calcule combien de traits sont dessinés, puis trace le trajet sur papier et compte-les pour vérifier ton calcul.

Fiche 6Suivre un code et dessiner

Pour dessiner le trajet d'un programme sans se tromper, on joue soi-même le rôle de la tortue ou du robot, ligne par ligne, en notant sa position et sa direction.

Le robot du test

  • avancer() : le robot avance d'un carreau dans la direction où il regarde, et trace le trait.
  • droite() et gauche() : le robot tourne d'un quart de tour sur place, sans avancer.
  • Repère sur la grille le point de départ et le sens dans lequel le robot regarde au départ.

La méthode en 4 étapes

  1. Regarde les retraits : entoure le bloc de chaque boucle.
  2. Calcule combien de tours fait chaque boucle.
  3. Remplis un tableau de suivi, un tour après l'autre, sans sauter de ligne.
  4. Trace sur la grille au fur et à mesure, puis vérifie que le nombre de traits correspond à ton calcul.

Fiche 7Lire les messages d'erreur

Un message d'erreur n'est pas une punition : il donne le type d'erreur et le numéro de ligne où Python s'est arrêté. Lis toujours ces deux informations avant de corriger.

ErreurCe qu'elle veut direOù chercher
SyntaxErrorPython ne comprend pas l'écriture de la lignedeux-points oubliés, parenthèse non fermée, faute de frappe dans for ou in
IndentationErrorle retrait est incorrectligne non décalée après :, retraits différents dans un même bloc, décalage inattendu
NameErrorPython ne connaît pas ce nomimport oublié, faute d'orthographe, majuscule en trop, fonction utilisée avant d'être définie
TypeErrorune commande reçoit un mauvais argumentargument manquant, en trop, ou du texte à la place d'un nombre

À retenir

  • L'erreur est parfois sur la ligne juste avant celle indiquée (souvent pour une parenthèse non fermée).
  • Un programme sans message d'erreur peut quand même être faux : si le dessin n'est pas le bon, c'est une erreur de logique (mauvais nombre de tours, mauvais angle, ligne mal indentée).
  • Corrige une seule erreur à la fois, puis relis tout le programme.
Je m'entraîne

Fiche 8Les fonctions

Une fonction est une recette à laquelle on donne un nom : on l'écrit une fois avec def, puis on l'utilise autant de fois qu'on veut en l'appelant par son nom.

def nom_de_la_fonction(parametre):    # 1. je DÉFINIS la recette
    instruction_1                      #    le corps, décalé de 4 espaces
    instruction_2

nom_de_la_fonction(50)                 # 2. je l'APPELLE : elle s'exécute

Le vocabulaire à maîtriser

  • Définir : écrire la recette avec def. À ce moment, rien ne se dessine.
  • Appeler : écrire le nom suivi de parenthèses. C'est là que la fonction s'exécute.
  • Paramètre : le nom entre parenthèses dans def, qui attend une valeur.
  • Argument : la valeur donnée à l'appel, qui remplace le paramètre.

Les règles

  • La ligne def finit par : et le corps est décalé, comme pour une boucle.
  • Une fonction se définit avant d'être appelée, sinon NameError.
  • Ne donne jamais à une variable de boucle le même nom qu'une fonction : elle l'écraserait.
  • Une fonction peut contenir une boucle, et peut en appeler une autre.
Je m'entraîne

Écris l'appel d'une même fonction avec trois arguments différents, et dessine ou décris ce que chaque appel produit.

Fiche 9Écrire un programme : méthode et vérifications

On n'écrit pas un programme d'un seul coup : on observe la figure, on cherche le motif, on écrit un petit morceau, on le vérifie en suivant son trajet, puis on complète.

Avant d'écrire

  1. Pose ton doigt sur le point de départ et suis la figure en disant chaque mouvement à voix basse (avance, tourne à droite…).
  2. Repère le motif qui se répète et compte combien de fois.
  3. Repère ce qui n'est pas répété : un déplacement au début, un virage entre deux parties. Ces lignes seront hors de la boucle.

Pendant l'écriture

  1. L'import en première ligne.
  2. Le motif seul, vérifié en traçant son trajet.
  3. La boucle autour du motif, avec le bon nombre de tours.
  4. Les lignes hors boucle, à la marge.

Exercice 1 · Que donne range ?Fiche 3

Pour chaque écriture, donne la liste des valeurs prises par la variable et le nombre de tours.

ÉcritureValeursNombre de tours
range(5)  
range(2, 6)  
range(1, 4)  
range(0, 10, 3)  
Voir la correction
  • range(5) : 0, 1, 2, 3, 4, soit 5 tours.
  • range(2, 6) : 2, 3, 4, 5, soit 4 tours (6 est exclu).
  • range(1, 4) : 1, 2, 3, soit 3 tours.
  • range(0, 10, 3) : 0, 3, 6, 9, soit 4 tours (on ajoute 3 à chaque fois, sans atteindre 10).

Exercice 2 · Combien de fois ?Fiches 4 et 5

Pour chaque programme, dis combien de fois chaque instruction du robot est exécutée.

from robot import *
for i in range(3):
    avancer()
    droite()
avancer()
from robot import *
for i in range(2):
    for j in range(3):
        avancer()
    gauche()
Voir la correction

Programme A : droite() est dans la boucle, donc exécuté 3 fois. avancer() est exécuté 3 fois dans la boucle, plus 1 fois après (ligne à la marge), soit 4 fois en tout.

Programme B : avancer() est dans les deux boucles : 2 × 3 = 6 fois. gauche() n'est que dans la boucle extérieure (4 espaces) : 2 fois.

Exercice 3 · Chasse aux erreursFiches 2, 4 et 7

Ce programme contient trois erreurs. Pour chacune, donne le numéro de la ligne, le type d'erreur et la correction.

from robot import *
for i in range(4)
    avancer()
  droite()
Avancer()
Voir la correction
  • Ligne 2 : il manque les deux-points à la fin de for i in range(4). C'est une SyntaxError.
  • Ligne 4 : droite() est décalé de 2 espaces au lieu de 4 (ou 0). C'est une IndentationError. On le décale de 4 espaces pour qu'il soit dans la boucle.
  • Ligne 5 : Avancer prend une majuscule, Python ne connaît pas ce nom. C'est une NameError. On écrit avancer().

Attention : Python s'arrête à la première erreur rencontrée. Il faut donc corriger, puis relire, pour découvrir la suivante.
